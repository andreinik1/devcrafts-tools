# 🛠️ DevCraft — Developer Utilities Suite

A collection of fast, modern, and client-side web developer utilities designed to streamline daily frontend workflows.

🌐 **Live Demo:** [vibedev.space](https://www.vibedev.space)

---

## 🚀 Included Tools

1. **SVG Cleaner** — Strip unnecessary attributes, optimize paths, and clean up SVG code.
2. **JSON-to-TypeScript** — Instantly convert JSON objects into clean TypeScript interfaces.
3. **PX-to-REM Converter** — Quick and accurate unit conversion for scalable typography.
4. **Image Converter** — Convert images between popular formats directly in the browser.
5. **Meta & OG Generator** — Generate precise Open Graph and meta tags for social media sharing and SEO.
6. **CSS Shadow Generator** — Visual tool to craft smooth, layered box-shadows with CSS output.

---

## 💻 Tech Stack

* **Framework:** React
* **Build Tool:** Vite
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Deployment & Analytics:** Vercel

## ⚙️ Local Development

Clone the repository and run it locally:

```bash
# Clone the repository
git clone [https://github.com/your-username/devcrafts-tools.git](https://github.com/your-username/devcrafts-tools.git)

# Navigate to project directory
cd devcrafts-tools

# Install dependencies
npm install

# Start development server
npm run dev
